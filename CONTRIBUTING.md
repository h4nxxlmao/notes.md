# Contributing

Contributions are welcome. Please keep changes aligned with the project's goals: keep it minimal, fast, dependency-free, and accessible.

## Development

There is no build setup or compiler. Just edit the source files and test in your browser.

- Keep all JavaScript vanilla without external runtime dependencies.
- Keep the custom parser safe: never insert raw user markdown into `innerHTML`.
- Match existing code formatting and CSS variables defined in `style.css`.

## Pull Requests

1. Fork the repo and create a branch (`git checkout -b fix/issue-name` or `feature/name`).
2. Make your changes and test them across both desktop and mobile layouts.
3. Open a pull request describing what you changed and why.
